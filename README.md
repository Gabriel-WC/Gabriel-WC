## 🩺 Projeto em destaque — ALFAMED

> Aplicativo de saúde **voltado ao paciente**, desenvolvido em **Flutter** e integrado a uma **API REST**. Projeto em equipe — e a melhor amostra do que sei fazer na prática.

<!-- 👉 Coloque aqui um GIF/print real do app, ex.:
<img src="https://raw.githubusercontent.com/AlfamedSoftware/NOME_DO_REPO/main/docs/demo.gif" width="260"/> -->

**🧩 Arquitetura**
- Organização **modular por _features_** (auth, agendamentos, prontuário, perfil…).
- **_Flavors_** de ambiente (dev/prod) para separar configurações e URLs de API.
- **Pipeline CI/CD** com GitHub Actions.
- Camada de serviço com models tolerantes a nulos, blindando a UI contra mudanças de contrato.

**✨ Funcionalidades**
- Cadastro e login de pacientes com autenticação e sessão.
- Agendamento de consultas (unidade → especialidade → vaga).
- "Meus agendamentos", prontuário (com exames) e anamnese.
- Perfil do paciente.

**🔧 Desafios que resolvi**
- **Login falhando no APK instalado:** diagnostiquei que o back-end (Better Auth) rejeitava as requisições do app por falta do header `Origin` (proteção CSRF) e corrigi enviando `Origin`/`Referer` nas chamadas de autenticação.
- **Tratamento de erros por código HTTP** (409/410/422) com mensagens claras ao usuário e recarga automática de vagas quando um horário fica indisponível.
- **Trabalho em equipe com Git:** integração de commits de colegas e resolução de conflitos mantendo o histórico limpo.

**🧰 Stack:** Flutter · Dart · API REST · Git · GitHub Actions &nbsp;·&nbsp; *(back-end da equipe em Better Auth + Elysia; minha atuação foi no app Flutter e na integração)*
